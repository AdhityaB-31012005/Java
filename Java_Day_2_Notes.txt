2. WHAT IS A VARIABLE?

A variable is a named memory location used to store a value.

Example:
int age = 21;

Here:
int  -> Data type
age  -> Variable name
21   -> Value
=    -> Assignment operator
;    -> End of statement


3. WHY DO WE NEED VARIABLES?

Instead of:
System.out.println(21);
System.out.println(21);
System.out.println(21);

we can write:
int age = 22;

System.out.println(age);
System.out.println(age);
System.out.println(age);

If the value changes, we only need to change the variable.


4. VARIABLE DECLARATION

Example:
int age;

This declares a variable named age that can store an integer.


5. VARIABLE INITIALIZATION

Giving a variable its first value is called initialization.

Example:
age = 21;

Declaration and initialization together:
int age = 21;


6. BASIC VARIABLE SYNTAX

dataType variableName = value;

Examples:
int age = 21;
double salary = 25000.50;
char grade = 'A';
boolean passed = true;


7. WHAT IS A DATA TYPE?

A data type tells Java what kind of value is stored in a variable.

Example:
int age = 21;
String name= "Adhitya";

int tells Java that age stores an integer.

Example:
double salary = 25000.50;

double tells Java that salary stores a decimal value.


8. JAVA DATA TYPES

Java data types can broadly be divided into:

Data Types
|
+-- Primitive
|
+-- Reference

Java has 8 primitive data types:

byte
short
int
long
float
double
char
boolean


9. INTEGER DATA TYPES

Java provides four integer types:

byte
short
int
long

Examples:
byte age = 21;
short year = 2026;
int salary = 50000;
long population = 1400000000L;

For normal integer calculations, int is generally the default choice.


10. int

int is the most commonly used integer type.

Examples:
int age = 21;
int marks = 85;
int numberOfStudents = 50;

Integer values are whole numbers such as:
10
25
100
-5
0


11. long

Use long when an integer value may exceed the range of int.

Example:
long population = 1400000000L;

The L tells Java that the literal is a long.


12. DECIMAL DATA TYPES

Java provides:
float
double

double:
double price = 99.99;
double average = 87.5;

double is generally the default choice for decimal calculations.

float:
float temperature = 36.5f;

The f tells Java that the literal is a float.


13. char

char stores a single character.

Examples:
char grade = 'A';
char gender = 'M';
char symbol = '#';

Character uses single quotes:
'A'

String uses double quotes:
"A"

Correct:
char letter = 'A';

Incorrect:
char letter = "A";


14. boolean

A boolean stores one of two values:

true
false

Examples:
boolean isPassed = true;
boolean isLoggedIn = false;


15. PRIMITIVE DATA TYPE SUMMARY

byte    -> Small integer
short   -> Small/medium integer
int     -> Normal integer
long    -> Large integer
float   -> Decimal value
double  -> Decimal value
char    -> Single character
boolean -> true or false

17. PRINTING TEXT WITH VARIABLES

Example:
int age = 21;
System.out.println("Age: " + age);

Output:
Age: 21

Example:
String name = "Adhitya";
int age = 21;

System.out.println("Name: " + name);
System.out.println("Age: " + age);

String stores a sequence of characters and is a reference type, not one of Java's 8 primitive types.


18. STRING VARIABLE

Examples:
String name = "Adhitya";
String city = "Puducherry";

System.out.println("Name: " + name);
System.out.println("City: " + city);


19. THE + OPERATOR WITH VARIABLES

The + operator can perform addition.

int a = 10;
int b = 20;

System.out.println(a + b);

Output:
30

When a String is involved:

System.out.println("Sum = " + a + b);

Output:
Sum = 1020

To get:
Sum = 30

use:
System.out.println("Sum = " + (a + b));

Parentheses make the addition happen first.


20. CHANGING VARIABLE VALUES

Example:
int age = 21;

System.out.println(age);

age = 22;

System.out.println(age);

Output:
21
22

After a variable has been declared, assign a new value without writing the data type again:
age = 22;


21. IDENTIFIERS

Variable names are called identifiers.

Examples:
age
studentName
totalMarks
average
salary

Rules:
- Can contain letters
- Can contain digits
- Can contain underscore (_)
- Can contain dollar sign ($)
- Cannot start with a digit
- Cannot contain spaces
- Cannot be a Java keyword
- Java is case-sensitive

Valid:
int age;
int studentAge;
int student_age;
int age2;

Invalid:
int 2age;
int student age;


22. JAVA IS CASE-SENSITIVE

These are different variables:

int age = 20;
int Age = 30;
int AGE = 40;

age, Age and AGE are three different identifiers.


23. VARIABLE NAMING CONVENTION

Java commonly uses camelCase.

Prefer:
int studentName;
int totalMarks;
int studentAge;

Meaningful names are better than unclear names such as:
int x;
int a;
int n;


24. LITERALS

A literal is a fixed value written directly in source code.

Examples:
10
25.5
'A'
true
"Hello"

Example:
int age = 21;
21 is an integer literal.

char grade = 'A';
'A' is a character literal.

boolean passed = true;
true is a boolean literal.


25. TYPE CONVERSION

Sometimes one data type needs to be converted into another.

Examples:
int -> double
double -> int

Two important categories:

Type Conversion
|
+-- Widening
|
+-- Narrowing


26. WIDENING CONVERSION

Widening converts a smaller compatible numeric type into a larger type.

Example:
int number = 100;
double value = number;

Here:
int -> double

Java performs this automatically.

Output:
100.0

This is also called implicit type conversion.


27. NARROWING CONVERSION

Narrowing converts a larger type into a smaller compatible type.

Example:
double number = 100.75;
int value = (int) number;

System.out.println(value);

Output:
100

The decimal part is lost.


28. TYPE CASTING

General syntax:
targetType variable = (targetType) value;

Example:
double price = 99.99;
int convertedPrice = (int) price;

System.out.println(convertedPrice);

Output:
99

Type casting can result in loss of information.


29. TYPE CASTING EXAMPLE

double value = 9.99;
int number = (int) value;

System.out.println(number);

Output:
9

Casting does not round the number.

9.99 -> 9
9.50 -> 9
9.01 -> 9


30. WIDENING VS NARROWING

Widening:
int number = 100;
double value = number;

No explicit cast is required.

Narrowing:
double number = 100.99;
int value = (int) number;

Explicit casting is required.


31. PRIMITIVE VS REFERENCE TYPES

Primitive examples:
int
double
char
boolean

Reference examples:
String
Arrays
Objects
Classes

Basic understanding:
Primitive types represent simple values.
Reference types refer to objects.

Reference types will be studied in more detail later.


32. GUIDED PROGRAM — STUDENT PROFILE

public class StudentProfile {

    public static void main(String[] args) {

33. GUIDED PROGRAM — BASIC CALCULATOR

public class Calculator {
